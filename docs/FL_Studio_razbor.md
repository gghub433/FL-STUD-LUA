## 1. Что это такое

### 1.1 Коротко

FL Studio — DAW (цифровая звуковая рабочая станция) бельгийской компании **Image-Line** (Гент). Вместо «дорожки = инструмент» в ней используется **паттерновая модель**: музыкальные идеи создаются как паттерны в **Channel Rack**, а затем раскладываются как клипы в **Playlist**. Лицензия бессрочная, с **Lifetime Free Updates**: купив редакцию один раз, вы бесплатно получаете все следующие версии этой редакции.

### 1.3 Позиционирование и платформы

- **Аудитория:** битмейкеры (хип-хоп, трэп, drill), продюсеры электронной музыки, начинающие продюсеры. Порог входа низкий: есть бесплатный триал без ограничения по времени и дешёвая Fruity Edition.
- **Платформы:** Windows 10/11 (64-bit) и macOS (Intel и Apple Silicon); одна лицензия покрывает обе ОС. **Linux официально не поддерживается** (энтузиасты запускают через Wine без гарантий).
- **Мобильные:** FL Studio Mobile (iOS/Android) — отдельный платный продукт. Его движок доступен внутри десктопной версии как плагин.
- **Экосистема:** FL Cloud (сэмплы, мастеринг, дистрибуция, подписка на сторонние плагины, с 2026 — облачные бэкапы проектов), Gopher (AI-ассистент).

### 1.5 Паттерновый воркфлоу: как это устроено и почему он хорош для битов

```
Channel Rack (инструменты/сэмплы) ──┐
   │  каждый канал отправлен на трек│микшера (Mixer Track)
   ▼                                 ▼
Pattern 1: Drums  ─┐              Mixer: инсерты → эффекты → Master
Pattern 2: Bass   ─┼─► Playlist: паттерн-клипы + аудиоклипы + клипы автоматизации
Pattern 3: Lead   ─┘     (на любой дорожке, в любой комбинации)
```

1. **Channel Rack** — список «каналов»: сэмплеров, синтезаторов, аудиоклипов, клипов автоматизации.
2. **Паттерн** — контейнер нот для всех каналов сразу: «Drums A», «Drums B (fill)», «Bass verse», «Chords». Ноты вводятся шагами в step-секвенсоре или в Piano Roll.
3. **Playlist** — полотно аранжировки. Паттерны рисуются на нём как клипы. Дорожки плейлиста **не являются** инструментами или каналами микшера: на одну дорожку можно положить паттерн, аудио и автоматизацию.
4. **Mixer** не связан с дорожками плейлиста. Звук идёт по цепочке «канал → трек микшера».

**Почему это подходит для битмейкинга и электроники:**

- 16-шаговая сетка повторяет логику драм-машин (808/909, MPC): кик, хэты и клэп набиваются за секунды.
- Вариация делается клонированием паттерна (Clone pattern), а не копированием десятков регионов.
- Аранжировка — «рисование» блоков: интро без баса, дроп со всем и т. д. Изменение паттерна обновляет все его копии в песне.
- Электронная музыка строится из повторяющихся блоков, и паттерн-модель описывает её естественнее, чем линейная запись дублей.

**Минусы модели:** в больших проектах десятки паттернов превращаются в лабиринт. Отчасти помогают Split by channel (разложить паттерн по каналам), пикер паттернов и Make unique. Для «живой» записи группы линейные DAW удобнее.

## 2. Ядро программы

### 2.1 Channel Rack

- Хранит **генераторы**: встроенный Sampler, FL-синтезаторы, сторонние VST/VST3/CLAP/AU, аудио- и автоматизационные каналы.
- **Channel Settings** сэмплера: Envelope/ADSR, фильтр, LFO, питч, растяжение (time-stretch), арпеджиатор, реверс, loop-точки.
- **Cut / Cut by** — группы заглушения (choke): закрытый хэт глушит открытый.
- **Target Mixer Track** — номер трека микшера, куда идёт звук канала.
- Группы каналов (фильтр отображения), **Layer**-каналы (один MIDI-вход на несколько инструментов), цвета, Graph Editor для шагов.

### 2.2 Step Sequencer

- По умолчанию 16 шагов на такт (1/16), длина паттерна меняется. **Swing** задаётся глобально.
- Параметры каждого шага в Graph Editor: velocity, release, pan, fine pitch, mod X/Y, shift.
- Шаги и Piano Roll — **одни и те же данные**: сложную партию из Piano Roll канал показывает мини-превью нот.
- Fill each 2/4/8 steps, Rotate (сдвиг), Randomize.

### 2.3 Playlist

- Типы клипов: **паттерн, аудио, автоматизация**.
- Инструменты: Draw, Paint, Delete, Mute, Slip, Slice, Select, Zoom, Playback.
- **Arrangements** — несколько версий аранжировки в одном проекте (с FL 20).
- **Time markers**: метки, loop-регионы, смена размера.
- **Performance Mode** — запуск клипов в реальном времени, аналог сессионного режима.
- **Consolidate** — рендер клипов/дорожки в аудио; Make unique; Split by channel; группировка дорожек.
- С 2025: у каждого аудиоклипа свои stretch/pitch/reverse (Alt/Cmd + двойной клик по клипу).

### 2.4 Piano Roll

Piano Roll считается одним из лучших MIDI-редакторов в индустрии.

**Инструменты тулбара:** Draw (карандаш), Paint (кисть), Delete, Mute, Slice, Select, Zoom, Playback.

**Меню Tools:**

| Инструмент | Что делает |
|---|---|
| Arpeggiate | Превращает аккорды в арпеджио по шаблонам |
| Articulate | Меняет длину нот и зазоры между ними (легато ↔ стаккато) |
| Chop / Quick chop | Режет ноты на ритмические фрагменты |
| Claw machine | Прореживает/переставляет ноты по паттерну («выкусывание») |
| Fill each N steps | Заполняет ноты через каждые N шагов |
| Flam | Добавляет форшлаги (флэмы) |
| Flip | Зеркально отражает ноты по высоте или времени |
| Legato / Quick legato | Тянет ноты до следующей |
| LFO | Модулирует свойства нот (velocity, pan…) формой LFO |
| Limit | Ограничивает ноты диапазоном или гаммой |
| Quantize / Quick quantize (в т. ч. только начала нот) | Квантизация |
| Randomize | Случайная генерация нот и свойств в выбранной гамме |
| Riff machine | Генератор мелодий и риффов из аккордов |
| Scale levels | Масштабирует значения свойств нот |
| Strum | «Гитарное» разложение аккордов по времени |
| Scripts (Python, `.pyscript`) | Пользовательские скрипты обработки нот (появились в эпоху FL 21) |

**Прочее:**

- Stamp — вставка аккордов и гамм.
- Подсветка гаммы и привязка к ней.
- **Chord Progression** (AI-генерация прогрессий, с 2024).
- **Chord Panel** — детектор аккордов в реальном времени (2026).
- **Подписи к нотам** (note labels, 2026).
- Ghost notes других каналов.
- Portamento/slide-ноты.
- Свойства ноты: velocity, release, fine pitch, pan, mod X, mod Y, цвет/MIDI-канал.
- Нижние лейны редактирования параметров, маркеры, группировка нот.

### 2.5 Mixer и маршрутизация

- **До 500 инсерт-треков** (с 2025 — «динамические»: добавляются и удаляются по мере надобности; раньше фиксировано 125), плюс Master и Current.
- **10 слотов эффектов** на трек, встроенный 3-полосный параметрический EQ, фаза, swap L/R, stereo separation.
- **Маршрутизация «любой в любой»**: отправки с регулировкой уровня, **sidechain** («Sidechain to this track»), «Route to this track only», многовыходные плагины.
- Автоматическая **компенсация задержки плагинов** (PDC) плюс ручная коррекция на трек.
- Запись на треке: выбор аудиовхода и арм.
- Многопоточная обработка треков.
- **Patcherize** (2025.2): превращает цепочку эффектов в один экземпляр Patcher.

### 2.6 Browser

- Дерево: сэмплы, пресеты, плагины (plugin database), проекты, история.
- Поиск, теги, избранное.
- Вкладка **Sounds** с библиотекой FL Cloud (роялти-фри, превью в темпе проекта).
- Интеграция с **Loop Starter** (2025; расширен в 2025.2 и 2026) — генерирует набор совместимых лупов для старта трека.

### 2.7 Patcher

Модульная среда внутри одного слота. Позволяет:

- собирать графы из генераторов и эффектов, параллельные цепочки, мульти-FX;
- выводить нужные ручки на одну «панель» (Surface) и сохранять всё как пресет;
- использовать внутренние контроллеры: **Peak Controller** (огибающая → модуляция, «ложный» сайдчейн), **Formula Controller**, **Envelope Controller**, **X-Y Controller**, **Control Surface**.

### 2.8 Автоматизация

- **Automation Clips** в Playlist: кривые разных типов (single curve, stairs, hold, pulse и др.), LFO-генератор внутри клипа.
- **Event Editor**: автоматизация внутри паттерна; в Fruity Edition исторически был единственным способом автоматизации.
- Запись движения ручек в реальном времени, **Link to controller** (привязка к MIDI-контроллеру) и Multilink.

### 2.9 Работа с аудио

| Инструмент | Назначение | Редакция |
|---|---|---|
| **Audio clips + запись** | Запись с входов в Playlist или Edison | Producer+ |
| **Edison** | Волновой редактор/рекордер в слоте: резка, спектральный вид, шумоподавление; с 2024 — AI-денойз и улучшенный declip | Producer+ ✅ |
| **Slicex** | Нарезчик брейков/лупов: авто-слайсинг, огибающие на слайс, выгрузка нарезки в Piano Roll | Producer+ ✅ |
| **Fruity Slicer 2** | Лёгкий слайсер с огибающими на слайс (2025.2) | Все ✅ |
| **Newtone** | Нотное редактирование высоты и времени монофонического аудио (коррекция вокала «по нотам») | Signature+ ✅ |
| **Pitcher** | Автотюн в реальном времени плюс гармонизация по MIDI | Signature+ ✅ |
| **NewTime** | Выравнивание и «варп» аудио по сетке | ⚠️ Signature+ (часть источников — Producer+) |
| **Time-stretch** | Режимы Resample и алгоритмы zplane élastique (E3 Generic, E3 Mono и др.) в сэмплере и клипах | Все |
| **Stem Separation** | AI-разделение на вокал, барабаны, бас и прочее (с 21.2) | ⚠️ сверяйте с compare |
| **Audio Logger** | Непрерывно пишет выход Master (последние ~60 с), чтобы не потерять удачную импровизацию (2026) | Все ✅ |

### 2.10 Форматы плагинов и экспорт

- **Хостинг:** VST2, VST3, **CLAP** (с 2024), AU (macOS). Сторонние плагины можно запускать в отдельном процессе (bridged). ARA2 **нет**.
- **FL Studio как плагин:** FL можно загрузить внутрь другой DAW как VST/AU-инструмент.
- **Экспорт:** WAV (16/24/32-float), MP3, OGG, FLAC, MIDI. Раздельный рендер треков микшера (стемы); в 2026.1.6 при этом можно включить рендер Master и Current. Zipped loop package (проект вместе с сэмплами). Видео через ZGameEditor Visualizer.

### 2.11 MIDI-контроллеры

- Любой class-compliant MIDI-контроллер, **Link to controller** и Multilink.
- **Python MIDI Scripting API** (с 20.7): для многих контроллеров есть родные скрипты.
- **Akai Fire** (сделан совместно с Image-Line) с 2026.1.6 по умолчанию работает через свой выделенный скрипт. Есть интеграция с Novation FLkey.
- В 2026.1.6 FL показывает уведомление при подключении нового MIDI-устройства.
- MIDI Out (управление внешним железом), IL Remote (мобильное приложение-контроллер).

| Lifetime Free Updates (в рамках редакции) | ✅ | ✅ | ✅ | ✅ |

**Главное:**

- **Fruity** подходит только для MIDI и паттернов. Записать вокал нельзя, полноценно работать с аудио тоже.
- **Producer** — первая «полная» DAW: запись, аудиоклипы без ограничений, Edison и Slicex.
- **Signature** добавляет не функции, а **плагины**: прежде всего вокальные (Pitcher, Newtone) и Gross Beat.
- **All Plugins** — тоже только плагины, эксклюзивы Image-Line.
- На старшую редакцию можно перейти, доплатив разницу. Базовые функции во всех редакциях одинаковые, начиная с Producer.

**Бесплатный вариант.** Официальный **триал** работает бессрочно, в нём есть все функции и плагины, водяных знаков нет. Ограничение одно: **сохранённый проект нельзя открыть повторно** до покупки лицензии. Экспорт в WAV/MP3 работает.

## 4. All Plugins Edition: эксклюзивы (нет ни в одной младшей редакции)

Список собран по официальной странице сравнения и описаниям плагинов. Там, где источники расходятся, стоит ⚠️. Плагины, которые Image-Line перенесла в младшие редакции (Sytrus, Maximus, DirectWave и др.), сюда **не** включены.

### 4.1 Синтезаторы

| Плагин | Тип синтеза | Типичное применение |
|---|---|---|
| **Harmor** | Аддитивный с субтрактивной архитектурой; ресинтез аудио и изображений | Сложные EDM-лиды и басы, «растягивание» сэмплов, саунд-дизайн |

## 5. Актуальная версия и что нового

**FL Studio 2026** вышла **7 июля 2026** (26.1.0.5530) бесплатным обновлением для всех владельцев лицензий. Затем вышли 2026.1.2 (20 июля) и **2026.1.6** (7 сентября 2026, 26.1.6.5639) — актуальная на дату разбора.

**Главное в 2026:**

| Что | Подробности |
|---|---|
| **FLEX переписан с нуля** | Новый синтез-движок, до −50% нагрузки на CPU на паках 2-го поколения. Новый браузер: поиск по всем пакам, фильтры, быстрый предпрослушивание. 8 бесплатных паков, 200+ пресетов. Первое крупное обновление с 2019 года |
| **Transmitter** (только APE) | Разделение на транзиенты и сустейн (см. 4.4) |
| **SoundFont Player** | Новый плеер банков SF2 (⚠️ в какие редакции входит — сверяйте) |
| **Note Arpeggiator** | Превращает входящие ноты в ритмичные, повторяющиеся и транспонированные паттерны (⚠️ редакция) |
| **FPC** | Несколько сэмплов на один пэд, то есть слои |
| **Gopher становится «агентным»** | Раньше только отвечал на вопросы, теперь **выполняет действия в проекте**: организует треки, маршрутизирует микшер, выставляет уровни, крутит параметры плагинов, пишет ноты в Piano Roll, создаёт VFX-скрипты |
| **FL Cloud Project Backup** | Облачные бэкапы: 500 МБ бесплатно, 5 ГБ (Plus), 1 ТБ (Pro). Можно сохранять в облако при каждом сохранении |
| **Audio Logger** | Tools → Audio Logger: непрерывно пишет выход Master (последние ~60 с) |
| **Loop Starter** | Расширенная библиотека жанров и лупов |
| **Piano Roll** | Chord Panel с распознаванием нот и аккордов в реальном времени, подписи к нотам |
| **Обучение** | Встроенные интерактивные туториалы (Loop Starter, step-секвенсор), опция «Remix a song» |

**Исправления в 2026.1.x (по 2026.1.6):**

- Экспорт: при разделении треков можно рендерить Master и Current.
- Точнее запись MIDI (меньше джиттера), в том числе при смене темпа во время воспроизведения.
- macOS: раздельный выбор устройств аудиовхода и выхода.
- Уведомление о подключении MIDI-устройства.
- Akai Fire по умолчанию работает через выделенный скрипт.
- Исправлены вылеты при загрузке проектов, в Piano Roll, Edison, FLEX, Sytrus, с ASIO и окнами плагинов.

> ⚠️ Часть деталей получена из вторичных источников (пресса, форум Image-Line в пересказе). Точная привязка отдельных пунктов к 2026.1.0 или 2026.1.x может отличаться. Официальный список: <https://www.image-line.com/fl-studio/release/2026>.

## 6. Экономика: кому какая редакция

### 6.1 Кому хватит Producer ($199)

- Битмейкерам, которые работают с сэмплами, лупами и сторонними синтами (Serum, бесплатный Vital, Diva и т. п.).
- Всем, кто записывает вокал или инструменты, но тюнит голос сторонним Auto-Tune или Melodyne.
- Тем, кто учится. Producer — минимальная редакция без искусственных ограничений по аудио. Fruity за $99 — ловушка для всех, кто когда-нибудь запишет голос.

### 6.2 Кому нужна Signature ($299)

- Хип-хопу и трэпу: **Gross Beat** — фирменный инструмент жанра, **Pitcher** и **Newtone** закрывают автотюн и коррекцию вокала без покупки Auto-Tune или Melodyne.

### 6.3 Кому реально нужна All Plugins ($499)

- **Саунд-дизайнерам и EDM-продюсерам**, которым нужен Harmor (ресинтез) и набор нишевых синтов: FM (Toxic Biohazard), физмоделирование (Sakura, Drumaxx), аддитивные Ogun и Morphine.
- Тем, кто **сводит и мастерит в коробке** и хочет закрыть задачи родными LuxeVerb, Emphasis и Transmitter.
- Тем, кто иначе купил бы 3–4 сторонних плагина по $100–200. При этом APE часто продаётся со скидкой до 50%, и тогда покупка математически выгоднее.

**Кому APE НЕ нужна:** тем, у кого уже есть любимые сторонние синты и эффекты (Serum/Pigments, FabFilter, Valhalla). Разница $200 с Signature уйдёт на плагины, которыми вы не будете пользоваться.

### 6.4 Какие сторонние плагины заменяют эксклюзивы APE (функционально, не 1:1)

| Плагин FL | Сторонние аналоги |

| Harmor | Arturia Pigments (гармонический и wavetable-движки), NI Razor, отчасти Xfer Serum |
| Toxic Biohazard | NI FM8, Dexed (бесплатный) |

| Sakura / Drumaxx | AAS Chromaphone и Strum, Sonic Charge Microtonic (синтез ударных) |
| Ogun / Morphine | Аддитивные синты (AIR Loom), тот же Harmor |

## 7. Сильные и слабые стороны

### Сильные

1. **Скорость от идеи до лупа.** Step-секвенсор и Piano Roll — лучшие в классе для битов и электроники.
2. **Lifetime Free Updates.** Купленная в 2010-х лицензия получила FL 20, 21, 2024, 2025 и 2026 бесплатно. Среди крупных DAW это уникально.
3. **Гибкий Playlist:** любой клип на любой дорожке, несколько аранжировок, Performance Mode.
4. **Сильные родные инструменты:** Sytrus, Harmor, FLEX, Gross Beat, Patcher.
5. **Одна лицензия на Windows и macOS.** Есть бессрочный триал со всеми функциями.
6. **Открытость:** CLAP, Python-скрипты для контроллеров и Piano Roll, FL как плагин в других DAW.
7. **Гигантское комьюнити:** туториалы, пресеты, шаблоны. Почти любой вопрос уже разобран на YouTube.

### Слабые

1. **Нет ARA2.** Melodyne, RX Connect и SpectraLayers работают только в неудобном режиме Transfer.
2. **Запись и комп дублей реализованы проще,** чем в Cubase, Studio Pro, Logic или Pro Tools. Для записи живых групп FL — не первый выбор.
3. **Нет нотного редактора** и полноценной работы с партитурой. Для оркестрового и киношного письма лучше Cubase, Dorico или Logic.
4. **Разрыв «дорожка плейлиста ≠ трек микшера ≠ канал»** сбивает с толку новичков и пришедших из линейных DAW. В больших проектах легко запутаться в паттернах.
5. **Нет нативного Dolby Atmos и объёмного звука** (на сентябрь 2026). Иммерсивный микс придётся делать в другой DAW или через сторонние решения.
6. **Нет Linux-версии.**
7. **Fruity Edition вводит в заблуждение:** «DAW за $99», которая не умеет записывать аудио.
8. **Уклон в облачные и AI-сервисы и подписки** (FL Cloud Plus/Pro, Plugins, Gopher). Базовая лицензия по-прежнему бессрочная, но часть новых функций (облачные сэмплы, мастеринг, бэкапы сверх 500 МБ, возможности Gopher) завязана на аккаунт или подписку.
9. **Интерфейс из множества плавающих окон** и плотная UI-логика: высокий порог «эргономической» привычки.
