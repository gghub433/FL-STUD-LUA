# FL LUA

Веб-DAW с паттерновым воркфлоу (Channel Rack → Piano Roll → Playlist → Mixer). Чистый JavaScript, без фреймворков и сборки;
звук считает **AudioWorklet**, события планируются по номеру сэмпла, а не таймерами. Тёмная тема и все графические элементы собственные.

```bash
cd web
node tools/serve.mjs          # http://localhost:8080/
npm test                      # unit-тесты движка, эффектов и инструментов (node:test)
node tests/e2e/run.mjs        # E2E в настоящем Chromium: клики + проверка, что AudioWorklet выдаёт звук
```

**Сборка и поставка**

```bash
npm run build                 # dist/: те же ES-модули, минифицированные esbuild (структура URL сохранена, worklet и worker работают как есть)
node tools/serve.mjs dist     # проверить production-сборку в браузере

cd desktop && npm ci          # настольное приложение: тот же сайт в собственном окне (Electron), браузер не нужен
npm start                     # запустить его из исходников
npm run dist                  # файлы для вашей системы в desktop/out (Windows: установщик и portable .exe, Linux: AppImage и .deb, macOS: zip)
npm run smoke:built -- out/linux-unpacked/fl-lua-desktop   # запустить собранное приложение и проверить, что звук идёт
```

Окно приложения отдаёт файлы из частной схемы `fllua://app/`, поэтому у приложения один постоянный адрес: проекты, сэмплы и плагины сохраняются между запусками. Разрешения на микрофон и MIDI выдаются сами, меню Electron скрыто (у программы своё меню), положение и размер окна запоминаются. Исходный код оболочки ― `desktop/main.js`.
Готовые файлы для всех систем собирает и **проверяет запуском** workflow `.github/workflows/release.yml` (в релизе: установщик `FL-LUA-windows-x64-setup.exe` и portable `FL-LUA-windows-x64.exe`, AppImage и `.deb`, zip для macOS; установщик и `.deb` тоже проверяются установкой и запуском). Файлы не подписаны: Windows SmartScreen покажет предупреждение, на macOS нужен правый клик → «Открыть».

**Обновления** (`desktop/updater.js`, без подписи кода): установщик Windows и AppImage обновляются через electron-updater: скачивают новую версию из GitHub Releases, сверяют sha512 из `latest.yml` / `latest-linux.yml` и ставят её при перезапуске. Portable `.exe`, `.deb` и macOS (неподписанное приложение не может заменить себя) узнают о новой версии через GitHub API и открывают её загрузку. Проверка идёт раз в день (Help → Check for updates…); ничего не скачивается без согласия.

Облегчённый вариант без Electron: `npm run exe` собирает `dist-exe/fl-lua` ― маленький запускатор, который поднимает локальный сервер и открывает **ваш браузер**.

Горячие клавиши: `Space` — play/stop, `F5` Playlist, `F6` Channel Rack, `F7` Piano Roll, `F9` Mixer, `F8` Browser, `Alt+F8` Plugin Picker, `Alt+T` — tap tempo, `Ctrl+S` / `Ctrl+O` — сохранить / открыть. Полный список и замена клавиш: **HELP → Keyboard shortcuts** (`F1`). Тема, размер и язык интерфейса: **OPTIONS → Interface**.

## Внешний вид

**OPTIONS → Interface → Customize look…** — всё оформление программы, сразу видно, что меняется:

* **Темы:** Классика, Океан, Лес, Виноград, Вишня, Золото, Без цвета, Полночь, Неон и стеклянные «Закат» и «Сияние». Свой вид сохраняется как тема (вместе с картинкой), его можно выгрузить в файл `.json` и загрузить на другом компьютере.
* **Цвет интерфейса:** оттенок, насыщенность, яркость и контраст — как ползунки темы в FL Studio. Перекрашивается всё: окна, Playlist, Piano Roll, микшер, индикаторы. Работает вместе со светлой темой.
* **Фон:** цвет, градиент или **своя картинка / фото**, с **размытием** и затемнением. Картинка остаётся в своих цветах. **Непрозрачность интерфейса** (40–100 %) решает, насколько фон просвечивает сквозь окна.
* **Матовое стекло:** меню, диалоги и сообщения пропускают размытый фон.
* **Сквозное окно** (настольная версия на Windows 11 и macOS): за окном FL LUA виден размытый рабочий стол (акрил / слюда на Windows, размытие macOS).
* **Шрифт** (системный, округлый, узкий, с засечками, моноширинный) и **скругление углов** кнопок и окон. Размер интерфейса и светлая тема — там же, в **OPTIONS → Interface**.

Всё хранится на этом компьютере, проект не меняется. Двойной щелчок по ползунку возвращает значение по умолчанию, **Reset** — классический вид.

## Где что находится

Раскладка как в FL Studio: **слева Browser** (звуки, пресеты, проекты — перетаскивайте их в проект), **на весь экран Playlist** (здесь собирается трек из паттернов), **поверх него Channel Rack** (инструменты и шаги ударных). Вверху — меню (FILE, EDIT, ADD, PATTERNS, VIEW, OPTIONS, TOOLS, HELP) и панель: транспорт (Play / Stop / Record, PAT ↔ SONG), темп, выбор паттерна и кнопки окон (WINDOWS): Playlist F5, Channel Rack F6, Piano Roll F7, Browser F8, Mixer F9, Plugin picker и ✦ AI-ассистент. Раскладка сбилась — **VIEW → Reset window layout**. Не знаете, куда нажать, — **HELP → Take the tour** или спросите AI-ассистента.

## AI-ассистент

Кнопка **✦** в панели (или **TOOLS → AI assistant…**) открывает чат с Claude. Он читает открытый проект и меняет его: темп, новые инструменты, шаги ударных, ноты мелодий и аккордов, параметры звука, эффекты на дорожках микшера, паттерны в Playlist, Play / Stop. Каждое изменение — обычная правка, **Ctrl+Z** её отменяет. Ещё он отвечает, где что в программе и как что сделать.

* Нужен свой API-ключ Anthropic: создайте его на console.anthropic.com (API keys) и вставьте по кнопке **API key…** в окне ассистента. Ключ хранится только на этом компьютере; сообщения и описание проекта уходят напрямую в Anthropic, оплата — с вашего аккаунта Anthropic.
* Модель — Claude Opus 5.5 через официальный SDK (`@anthropic-ai/sdk`, собран в `src/vendor/anthropic-sdk.js` командой `node tools/vendor-sdk.mjs`).

## Flux

Синтезатор с пресетами: **ADD → Flux — preset synth**. Слева библиотека (пэды, лиды, басы, клавишные, плаки, медь, колокольчики, эффекты), справа выбранный звук и 8 макро-ручек с названиями под этот звук (Яркость, Резонанс, Атака, Пространство, Панч, Саб…). Середина ручки — звук как задуман, влево — меньше, вправо — больше. Любую макро-ручку можно автоматизировать (правый клик).

## Облачный бэкап

**OPTIONS → Cloud backup…** → **Choose folder…**: каждые 2–30 минут, пока проект меняется, его копия пишется в подпапку `FL LUA backups` выбранной папки. Выберите папку Яндекс Диска, Google Drive, OneDrive или Dropbox — их программа сама отправит копии в облако. Хранятся 30 последних копий каждого проекта; копия открывается как обычный проект (**FILE → Open**). В браузере работает в Chrome и Edge.

## Плагины VST3, VST2, CLAP и AU

Настольная версия подключает синтезаторы и эффекты, установленные на компьютере, в форматах **VST3**, **VST2**, **CLAP** и (на macOS) **AU**: Vital, Surge XT, Serum, Sylenth1, Massive, Diva, Dexed, FabFilter, Valhalla и любые другие.

**Как подключить:**

1. **OPTIONS → Manage plugins… → Find plugins.** Программа сама просматривает стандартные папки (таблица ниже), вписывать пути не нужно. Если плагины лежат в другом месте, нажмите **Add folder…**.
2. **Инструмент:** **ADD → VST / CLAP plugin**, или Plugin picker, или Browser → **Plugin database** (двойной клик или перетаскивание). **Эффект:** слот микшера → **VST / CLAP plugin**. Рядом с названием видно формат: VST3, VST2, CLAP или AU. Если у плагина есть несколько форматов, выбирайте любой.
3. Откроется окно самого плагина. В окне канала или слота FL LUA, как в FL Studio, есть обёртка: показать или скрыть окно плагина, **Reload**, поиск параметра и ручки всех параметров.

**Что работает:**

* Ноты из Piano Roll, Step Sequencer и MIDI-клавиатуры уходят в плагин. Pitch bend, CC и aftertouch с контроллера тоже.
* Любой параметр плагина автоматизируется как у встроенных: правый клик по ручке, MIDI learn, запись движений. Движения ручек в окне самого плагина тоже записываются.
* Настройки плагина (пресет и всё остальное) сохраняются в проекте `.fllua`, и проект открывается с ними же. Если на другом компьютере нет этого плагина, канал помечается, а остальное работает.
* Экспорт (WAV / MP3 / …, стемы) считает те же плагины и ждёт каждый блок: пропусков нет даже у тяжёлых плагинов. Каждый плагин начинает экспорт с чистого листа.
* Плагины работают в отдельном процессе. Если плагин упадёт, FL LUA не закроется: канал замолчит, а **Reload** запустит его снова.
* Задержка: плагины звучат на несколько миллисекунд позже встроенных (по умолчанию 3 блока, около 8 мс при 48 кГц). Микшер это компенсирует, всё играет ровно. Меньше задержка или меньше щелчков на слабом компьютере — **Manage plugins… → Plugin delay**.

| Система | Где программа ищет плагины |
|---|---|
| Windows | VST3: `C:\Program Files\Common Files\VST3`, `%LOCALAPPDATA%\Programs\Common\VST3`; CLAP: `…\Common Files\CLAP`, `%LOCALAPPDATA%\Programs\Common\CLAP`; VST2: `C:\Program Files\VSTPlugins`, `C:\Program Files\Steinberg\VSTPlugins`, `…\Common Files\VST2`, `…\Common Files\Steinberg\VST2` и папка из реестра (`HKLM\SOFTWARE\VST`) |
| macOS | `/Library/Audio/Plug-Ins/VST3`, `/CLAP`, `/VST` и то же в `~/Library`; Audio Units — все, что установлены в системе (папки не нужны) |
| Linux | VST3: `~/.vst3`, `/usr/lib/vst3`, `/usr/local/lib/vst3`; CLAP: `~/.clap`, `/usr/lib/clap`, `/usr/local/lib/clap`; VST2: `~/.vst`, `/usr/lib/vst`, `/usr/local/lib/vst`, `~/.lxvst`, `/usr/lib/lxvst`, `/usr/local/lib/lxvst` |

Плюс папки из переменных `VST_PATH`, `CLAP_PATH` (на Linux ещё `VST3_PATH`, `LXVST_PATH`) и добавленные вручную. В папках VST2 обычно лежат и вспомогательные библиотеки плагинов: программа узнаёт их и не показывает как ошибки. Как это устроено: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md), раздел 20.

## Чего нет и почему

* **32-битные плагины** не подключаются: FL LUA 64-битная, а мост для старых 32-битных плагинов нужен редко. Программа прямо пишет, что плагин 32-битный.
* **AU** только на macOS: на других системах Audio Units не существует.
* **В браузерной версии** нет VST / CLAP / AU: это машинный код, ему нужен свой процесс на компьютере. В браузере работают встроенные плагины, Plugin store и веб-плагины **WAM 2.0**.
* **Apple Silicon** поддерживается: `FL-LUA-macos-arm64.zip` в каждом релизе — родная сборка для M1–M4.

## Совместная работа по локальной сети

**TOOLS → Collaboration…** Любой компьютер с настольной FL LUA становится сервером: **Start session** показывает адрес (например `192.168.1.20:47800`) и код из шести знаков. На других компьютерах в той же сети (Wi-Fi или кабель): **Join**, адрес и код. Все работают над проектом сервера; кто завершает сессию — у всех остаётся последняя версия, и следующую сессию может начать любой участник на своём компьютере.

* Правки, движения ручек, новые каналы, ноты, клипы, эффекты и записанный звук сразу видны всем. Списки с id (каналы, ноты, клипы, маркеры) сливаются поэлементно: двое могут одновременно добавлять каналы или двигать разные клипы, работа обоих сохраняется. Одно и то же поле в один момент — побеждает последняя правка.
* **Отмена** возвращает только ваши правки, работа других остаётся. Воспроизведение, текущий паттерн, выбранная дорожка микшера и показанная аранжировка у каждого свои.
* Записи и импортированные файлы передаются по сети тому, кому они понадобились. Плагины WAM загружает каждый участник сам по их адресу.
* Сервер есть только в настольном приложении (браузер не умеет его открыть); подключиться можно и из браузерной версии, открытой на `localhost`. Брандмауэр Windows при первом запуске сессии спросит разрешение — разрешите для частных сетей. До 16 участников. Через интернет без VPN (например, Tailscale или ZeroTier) не работает.

## Плагины WAM (Web Audio Modules 2.0)

Сторонние инструменты и эффекты открытого веб-стандарта [WAM 2.0](https://www.webaudiomodules.com): **ADD → Instrument plugin → WAM plugin…** (канал) или **WAM plugin…** в списке эффектов слота микшера. Вставьте адрес главного модуля плагина (обычно `…/index.js`); в комплекте два примера (`wam/example-synth`, `wam/example-tremolo`), чтобы попробовать без интернета. Каталог плагинов: [webaudiomodules.com/community](https://www.webaudiomodules.com/community/).

* Окно канала или слота показывает собственный интерфейс плагина (или ползунки его параметров), **Change…** загружает другой, **Reload** — заново.
* Адрес и состояние плагина хранятся в проекте: сохранение, автосохранение, отмена, смена аудиоустройства — плагин возвращается с теми же настройками.
* Звук идёт через движок как у встроенных плагинов (микшер, маршрутизация, PDC); у WAM-эффекта задержка ровно один блок (128 сэмплов) плюс заявленная плагином, микшер её компенсирует. Ноты WAM-инструменту приходят прямо в его процессор, с точностью до сэмпла (на один блок позже встроенных).
* Экспорт, стемы и анализ громкости проекта с WAM-плагинами рендерятся через `OfflineAudioContext` с теми же плагинами (быстрее реального времени).
* До 16 WAM-плагинов одновременно. Плагин с другого сайта должен разрешать загрузку (CORS). Автоматизации параметров WAM-плагинов пока нет. Плагин ― это код: загружайте только из источников, которым доверяете.

## Patcher

Модульная среда как плагин: **Channel Rack → Add → Patcher** (генератор) или слот микшера **→ Patcher** (эффект).
Узлы: Audio In/Out, Note In, Macro (16 ручек с автоматизацией и MIDI), LFO, Envelope, Envelope follower, Random, Math, Map, Volume/Pan, Crossfade, Transpose, Note filter, Chord, Velocity и **любой генератор и эффект** программы.
Тяните от точки справа у узла к точке слева у другого; точки раскрашены по виду сигнала (звук, управление, ноты). Кнопка ⇄ у параметра делает из него вход для модулятора. Фабричные патчи: **Patches ▾**.

## Аудиоредактор

**Tools → Audio editor** (пустой, с записью), **Edit an audio file…**, кнопка **Edit…** у Sampler, пункты контекстных меню клипа и сэмпла в Browser.
`Space` — воспроизведение, `Ctrl+C/X/V`, `Del`, `Ctrl+Z/Y`, колесо — зум, `Shift`+колесо — прокрутка, `Z` — привязка к нулям.

## Scope, Peak controller, Polish

Три эффекта для слота микшера: **слот → Choose effect…** (группы Analysis, Control, Enhance), Plugin picker или Browser → **Plugin presets → Effects**.

* **Scope** — анализатор, звук проходит без изменений (бит в бит). В окне эффекта вживую: осциллограф (L и R, синхронизация по переходу через ноль, окно 2–200 мс), спектр с логарифмической шкалой частот (наклон, удержание пиков), векторскоп и индикаторы пика и RMS с корреляцией каналов. Ручка **View** показывает всё сразу или один вид крупно. Пока окно закрыто, Scope ничего не считает.
* **Peak controller** — следит за уровнем сигнала дорожки и двигает привязанные ручки, как LFO-контроллер: правый щелчок по любой ручке → **Link to controller** → «Peak controller · дорожка / слот». Ручки: Base (значение в тишине), Amount (отрицательное — ручка уходит вниз на громком, так делается «накачка»), Tension (изгиб), Input gain, Attack, Release, детектор Peak / RMS, свой LFO и **Mute audio** (дорожка только управляет, сама не звучит). В окне — уровень, выход и список привязок с диапазоном и инверсией. Работает и при экспорте.
* **Polish** — улучшайзер одной ручкой: **Amount** 0–100 % и четыре режима (Warm, Bright, Wide, Punch) — разные смеси мягкой трёхполосной компрессии, насыщения, расширения стерео и тембра. Выход не поднимается выше −0,3 dBFS, на 0 % эффект полностью выключен.
