# Пакеты плагинов (plugin packs)

Пакет — это **один самодостаточный ES-модуль** с генераторами, эффектами, звуками (сэмплами, которые делает код) и скриптами MIDI-контроллеров, который ставится из **Tools → Plugin store…** (или ADD → Get more plugins…) и работает так же, как встроенные плагины: в Channel Rack, в слотах микшера, в Patcher, в автоматизации, в экспорте.

## Магазин

* **Included with FL LUA**: пакеты из папки `packs/` (после сборки `dist/packs/`, внутри exe тоже). Установка в один клик.
* **Install from file…** / **From address…**: любой `.flpack.js`. Перед установкой показывается предупреждение и SHA-256 файла.
* **Add catalog…**: адрес `catalog.json` (см. ниже), его пакеты появляются в списке; установка сверяет SHA-256 с каталогом.
* Установленные пакеты хранятся в браузере (IndexedDB) и подключаются при старте до загрузки любого проекта. Удаление: **Remove**; плагины выгружаются после перезагрузки (worklet не умеет забывать модули).
* Проект, которому нужен незаполненный пакет, открывается без этих плагинов, а программа называет недостающие пакеты и плагины. **Не сохраняйте такой проект поверх оригинала**, пока не поставите пакет.

> **Безопасность.** Пакет — это код, он выполняется в странице с теми же правами, что и сама программа (ваши проекты и сэмплы в этом браузере). Ставьте пакеты только от тех, кому доверяете. Проверка при установке отсекает испорченные пакеты (самотест, см. ниже), но не злонамеренные.

## Что в комплекте

| Пакет | Что внутри |
|---|---|
| **FL LUA Synths** (`fllua-synths`) | **Acid Bass**: моно-бас с лестничным фильтром, акцентом (velocity выше 80 %) и слайдом (перекрывающиеся ноты); **Tri-Osc**: три осциллятора, sync, кольцевая модуляция, FM, мультирежимный фильтр, две огибающие, glide; **Chip**: пульс, треугольник и шум как в игровых консолях, арпеджио, sweep, вибрато, разрядность и понижение частоты; **Additive**: до 64 парциалов, наклон спектра, чёт/нечёт, форманта, негармоничность, морфинг двух спектров, затухание верхов |
| **FL LUA Effects** (`fllua-effects`) | **Soft Clipper** (4 кривые, оверсэмплинг), **Maximizer** (3 полосы + look-ahead лимитер, сообщает задержку), **Hyper Chorus** (до 8 голосов), **Waveshaper** (8 кривых), **Overdrive** (tube / crunch / fuzz), **Delay Bank** (4 независимых отводки, синхронизация с темпом), **Pitcher** (монофонический корректор высоты: YIN + гранулярный сдвиг, привязка к строю) |
| **FL LUA Drum Machines** (`fllua-drum-machines`) | **DM-8** и **DM-9**: аналоговые драм-машины, синтез в реальном времени на нотах General MIDI, уровень, строй и затухание каждого барабана |
| **FL LUA Keys** (`fllua-keys`) | **E-Piano**, **Strings**, **Piano**, **Choir**: клавишные, синтезированные в реальном времени |
| **FL LUA Sounds** (`fllua-sounds`) | 52 сэмпла, которые делает код: бочки, малые, клэпы, хэты и перкуссия драм-машин, басы, стэбы и пэды синтезаторов, гласные, FX и лупы 120 BPM. Появляются в Browser (Packs → FL LUA Sounds) |
| **FL LUA Controller Scripts** (`fllua-controllers`) | скрипты MIDI-контроллеров: ручки на выбранный канал (CC 21–28 / 70–77), фейдеры на микшер (CC 7 по каналам), пэды на канале 10 всегда играют барабаны. Включаются в **TOOLS → MIDI settings** |

Все плагины написаны с нуля для FL LUA; у каждого есть фабричные пресеты (Presets ▾ и Browser).

## Формат пакета

```js
globalThis.__flluaRegisterPack({
  id: 'my-pack',                 // 2–31 символов: a-z, 0-9, «-»
  name: 'My Pack', version: '1.0.0', author: 'Me', license: 'MIT', description: '…',
  api: 1,                        // версия API плагинов (текущая: 1)
  plugins(api) {
    const { def, bool, choice, defaults } = api.params;
    const { TAU, mtof, Biquad } = api.dsp;
    const schema = [def('gain', 'Gain', 0, 1.5, 0.8)];
    class Synth { /* см. ниже */ }
    return {
      instruments: { bass: { schema, meta: { name: 'My Bass', kind: 'bass', rootDefault: 36, description: '…' }, create: (sr, host) => new Synth(sr), presets: { Init: { gain: 0.5 } } } },
      effects: { /* то же самое для эффектов */ },
      controllers: { /* скрипты MIDI-контроллеров, см. ниже */ },
    };
  },
  sounds(api) {                  // необязательно: сэмплы, которые делает код (см. ниже)
    return { Kicks: { 'deep-kick': { name: 'Deep kick', gen: (sr) => new Float32Array(sr / 2) /* … */ } } };
  },
});
```

Файл **не импортирует ничего**: всё, что нужно, приходит в `api`. Один и тот же файл исполняется в странице (схемы параметров, интерфейс), в AudioWorklet (звук) и в воркере экспорта (офлайн-рендер). Типы плагинов получают пространство имён: `<id пакета>.<имя плагина>` (`fllua-synths.acid`), поэтому пакеты не конфликтуют друг с другом и со встроенными плагинами.

### `api`

| | |
|---|---|
| `api.params` | `def(id, name, min, max, default, {unit, curve:'lin'\|'log'\|'pow', int, step, group})`, `bool`, `choice(id, name, [options], default)`, `defaults(schema)`, `schemaMap`, `clampParam`, `toNorm`, `fromNorm`, `format` |
| `api.dsp` | `TAU, clamp, lerp, dbToGain, gainToDb, mtof, semi, fastTanh, panGains, Noise, Biquad, SVF, OnePole, DelayLine, LFO, ADSR, DAHDSR, polyBlep, hermite, SYNC_DIVS, SYNC_LABELS, timeCoef` |
| `api.fft` | `FFT, getFFT, hann` |
| `api.BLOCK`, `api.PPQ` | размер блока (128) и тиков на четверть (96) |

Идентификаторы параметров: буква и до 30 букв, цифр, `_`. Параметры с `curve: 'log'` должны иметь `min > 0`.

### Генератор

`create(sr, host)` возвращает объект:

| метод | |
|---|---|
| `setParam(id, value)` | значение уже ограничено схемой |
| `noteOn({key, vel, pan, fine, rel, len, …})` | `key` 0–127, `vel` 0..1, `fine` в центах |
| `noteOff(key)`, `allOff()`, `chokeAll()` (необязательно) | |
| `process(L, R, i0, i1)` | **добавляет** звук в `L[i0..i1)` и `R[i0..i1)`; движок вызывает его отрезками между событиями, поэтому нота стартует на точный сэмпл |
| `get active` | `true`, пока плагин звучит (иначе канал пропускается) |

### Эффект

`create(sr, host)` возвращает объект с `setParam(id, v)`, `process(L, R, n, ctx)` (обрабатывает **на месте** `L[0..n)`, `R[0..n)`; `ctx.scL/scR` ― sidechain или `null`), необязательно `reset()`, `setExtra(obj)`, свойство `latency` (в сэмплах, микшер компенсирует задержку) и `meters`. `host.tempo` и `host.playing` доступны для синхронизации с темпом.

### Звуки

`sounds(api)` возвращает `{ категория: { id: { name, gen(sampleRate) } } }`. `gen` возвращает `Float32Array` (моно) или `[L, R]`, не длиннее 60 секунд; звук делается при первом использовании на частоте проекта и дальше ведёт себя как обычный сэмпл (Sampler, FPC, Multisampler, перетаскивание в плейлист, экспорт). Id звука в проекте: `pack:<id пакета>:<id звука>`; если пакета нет, программа называет недостающие звуки. До 500 звуков в пакете; `gen` должен быть детерминированным (без `Math.random()`, берите `api.dsp.Noise`).

### Скрипты контроллеров

`controllers: { id: { meta: { name, description }, ports: ['Launchkey', …], create(api) } }`. Скрипт работает в странице, включается в **TOOLS → MIDI settings** и видит сообщения устройств, в имени которых есть одна из строк `ports` (пустой список ― все устройства), раньше самой программы. `create(api)` возвращает `{ onMidi(bytes, deviceName) → true, если сообщение использовано; dispose() }`.

| `api` | |
|---|---|
| `play()`, `stop()`, `record()`, `toggle()`, `action(id)`, `playing`, `tempo`, `setTempo(bpm)` | транспорт (`action` ― те же действия, что у привязки транспорта в MIDI settings) |
| `channels()`, `selected`, `select(id)`, `noteOn(key, vel, ch?)`, `noteOff(key, ch?)` | каналы и ноты (по умолчанию ― выбранный канал) |
| `setParam(addr, 0..1)`, `getParam(addr)`, `channelParams(id?)`, `mixerVolume(track, 0..1)` | параметры как положение ручки; адреса вида `ch:<id>:p:<параметр>`, `mx:<дорожка>:vol` |
| `send(bytes, port?)`, `toast(text)` | MIDI наружу (свет на контроллере) и сообщение в программе |

### Чего избегать

Выделять память в `process`; `Math.random()` (берите `api.dsp.Noise`: результат должен повторяться при экспорте); обращаться к `document`, `window`, `fetch`, `eval`: в AudioWorklet их нет, а тесты каталога такие файлы отвергают.

## Самотест при установке

`registerPack` проверяет форму пакета, схемы параметров и **играет каждый плагин**: ноты (низкие, высокие, аккорды, noteOff) или шум с тишиной, причём с каждым параметром в минимуме и в максимуме. Каждый звук делается один раз (на 11 025 Гц) и проверяется на NaN и уровень; скрипт контроллера создаётся и получает несколько сообщений. Отвергается пакет, который выдаёт NaN или уровень выше +24 дБ, падает с исключением, отдаёт отрицательную `latency` или слишком медленный для реального времени. Причина показывается в магазине.

## Каталог и публикация

`packs/catalog.json` описывает пакеты и их контрольные суммы; он собирается командой

```bash
node tools/make-catalog.mjs          # перезаписать packs/catalog.json
node tools/make-catalog.mjs --check  # проверить, что он актуален (тесты и CI делают это сами)
```

Формат: `{ "catalog": 1, "name": "…", "packs": [{ id, name, version, author, license, description, file, size, sha256, plugins:[{kind, name, description}] }] }`; `file` ― путь относительно самого каталога. Чтобы раздавать свои пакеты, выложите `catalog.json` и файлы пакетов рядом на любом статическом хостинге (достаточно GitHub Releases или GitHub Pages; нужны CORS-заголовки) и дайте пользователям адрес каталога: **Plugin store → Add catalog…**.

Новая версия пакета: поднимите `version` (магазин покажет **Update**) и пересоберите каталог.
